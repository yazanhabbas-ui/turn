# دليل مسؤول نظام دور

## 1. لمن هذا الدليل

هذا الدليل لمن يهيّئ نظام دور ويديره: **المسؤول العام** للمؤسسة كلها، و**مسؤول المدينة** لمدينة واحدة. أنت من يحدد عدد المدن والفروع والمكاتب، والخدمات التي يطلبها الزوار، ومن يعمل أين، وكيف تصل التذاكر إلى الموظفين، وكيف يبدو النظام ويعمل.

هناك دوران للمسؤولين. يستخدمان الشاشات نفسها، لكن ما يظهر لكل منهما مختلف.

|                      | المسؤول العام                                              | مسؤول المدينة                                                   |
| -------------------- | ---------------------------------------------------------- | --------------------------------------------------------------- |
| النطاق               | المؤسسة كلها: كل المدن والفروع                             | المدينة (أو الفروع) التي مُنح الدور عليها فقط                   |
| المدن                | ينشئ المدن ويعدّلها ويؤرشفها                               | لا يستطيع فتح صفحة **المدن**                                    |
| الأدوار              | ينشئ الأدوار ويعدّلها وينسخها                              | يعرض الأدوار فقط                                                |
| الإعدادات            | كل الأقسام على مستوى المؤسسة والمدينة والفرع               | الأقسام التي يجوز تخصيصها للمدينة أو الفرع فقط، ولمدينته وفروعه |
| الإشعارات            | حالة القنوات والرسائل التجريبية والحدود وصياغة الرسائل     | اختيارات الأحداث على مستوى الفرع وسجل الإرسال                   |
| المستخدمون           | يمنح أي دور، بما فيها أدوار المؤسسة كلها                   | يمنح فقط الأدوار والنطاقات التي يملكها هو                       |
| حالة النسخ الاحتياطي | يرى بطاقة **النسخ الاحتياطي لقاعدة البيانات** في نظرة عامة | لا يراها                                                        |

لا يعرض الشريط الجانبي إلا الصفحات التي يسمح بها دورك. إن لم تجد صفحة مذكورة هنا فدورك لا يشملها.

> **ملاحظة:** كل تغيير يجريه المسؤول يُطبَّق فوراً ويُسجَّل في **سجل التدقيق**. لا حاجة إلى إعادة تشغيل أي شيء.

## 2. قبل أن تبدأ

1. افتح دور في المتصفح وأدخل **البريد الإلكتروني** و**كلمة المرور**، ثم اضغط **تسجيل الدخول**. إذا طلبت الصفحة **رمز المنشأة** فأدخله أيضاً.
2. إذا كان التحقق بخطوتين مفعّلاً لحسابك، فأدخل الرمز المكوّن من 6 أرقام من تطبيق المصادقة واضغط **تحقق**.
3. اضغط اسمك في أعلى الصفحة لفتح **ملفي الشخصي**، ثم اتبع الرابط **كلمة المرور والتحقق بخطوتين واللغة**. من هناك يمكنك **تغيير كلمة المرور** وضبط **لغة الواجهة** (العربية أو الإنجليزية) وتفعيل التحقق بخطوتين بتطبيق مصادقة. ويمكن تبديل المظهر الفاتح أو الداكن من الشريط العلوي.
4. إذا كان لحسابك أكثر من مساحة عمل، فتظهر في الشريط العلوي كروابط. اختر **الإدارة**.

> **نصيحة:** فعّل التحقق بخطوتين لكل حسابات المسؤولين. ومن **الإعدادات ← الأمان** يمكنك جعله إلزامياً لأدوار كاملة.

![صفحة نظرة عامة للمسؤول العام](shot:admin-overview)

## 3. تعرّف على شاشتك

**نظرة عامة** هي الصفحة الأولى. ترحّب بك وتعرض خمسة عدّادات: **الفروع** و**المكاتب** و**المستخدمون** و**أسباب الزيارة** و**الأدوار**. ويحسب عدّاد مسؤول المدينة مدينته فقط.

![صفحة نظرة عامة لمسؤول مدينة: صفحات أقل في الشريط الجانبي](shot:admin-overview-city)

قد تظهر تحت العدّادات بطاقات تحذير:

- بطاقة **التغطية** تظهر عندما لا تكون في بعض الفروع أي طريقة لإصدار التذاكر (لا موظف استقبال، وإصدار التذاكر من شاشة الموظف متوقف، ولا جهاز تسجيل ذاتي مقترن). فيها زر **فتح الفروع**.
- بطاقة ثانية تظهر عندما يكون في فرع خدمات تُقدَّم في القاعات ولا يستطيع أحد تقديمها. فيها زر **فتح الإعدادات**.
- بطاقة **النسخ الاحتياطي لقاعدة البيانات** (للمسؤول العام فقط) تعرض **تم أخذ نسخة احتياطية** أو **النسخة الاحتياطية متأخرة** أو **فشلت آخر نسخة احتياطية** أو **لا توجد نسخة احتياطية مسجلة**.

يعرض الشريط الجانبي صفحات الإدارة:

| الصفحة                 | الغرض منها                                                    |
| ---------------------- | ------------------------------------------------------------- |
| **نظرة عامة**          | العدّادات والتحذيرات                                          |
| **المستخدمون**         | من يسجّلون الدخول، و**الدعوات**، و**الطلبات**                 |
| **الأدوار والصلاحيات** | ما يُسمح به لكل دور                                           |
| **المدن**              | المدن وإعداداتها (المسؤول العام)                              |
| **الفروع والمكاتب**    | الفروع والطوابق والمكاتب والقاعات                             |
| **أسباب الزيارة**      | الخدمات التي يأتي من أجلها الزوار                             |
| **مجموعات الموظفين**   | فرق الموظفين                                                  |
| **قواعد التوزيع**      | كيف تصل التذاكر إلى الموظفين                                  |
| **المحاكاة**           | تجربة القواعد على يوم معاد تشغيله                             |
| **الشاشات**            | شاشات الانتظار والأجهزة والإعلانات والصوت (راجع دليل الشاشات) |
| **الإشعارات**          | واتساب والرسائل النصية والبريد للزوار                         |
| **الإعدادات**          | كل الخيارات                                                   |
| **طلبات الخصوصية**     | تصدير بيانات زائر أو حذفها                                    |
| **سجل التدقيق**        | من غيّر ماذا ومتى                                             |

التقارير ولوحة المتابعة المباشرة مساحتا عمل منفصلتان في الشريط العلوي، وليستا ضمن الشريط الجانبي للإدارة.

## 4. المهام اليومية

### 4.1 الإعداد لأول مرة: الترتيب الصحيح

اتبع هذا الترتيب لأن كل خطوة تحتاج إلى ما قبلها.

1. **الهوية**: من **الإعدادات ← الهوية**. حدد **اسم المنشأة** وارفع **الشعار** واختر الألوان.
2. **المدن** (المسؤول العام): أضف كل مدينة.
3. **الفروع والمكاتب**: أضف الفروع والطوابق والمكاتب، والقاعات إن كنت تستخدمها.
4. **أسباب الزيارة**: عرّف كل خدمة وبادئة تذاكرها والبيانات المطلوبة ومن يخدمها.
5. **المستخدمون والموظفون**: أنشئ الأشخاص وامنحهم الأدوار وهيّئ الموظفين.
6. **مجموعات الموظفين** (اختياري): ضع الموظفين في فرق.
7. **الورديات**: من **الإعدادات ← الموظفون**.
8. **قواعد التوزيع**: اختر طريقة وصول التذاكر إلى الموظفين، وجرّبها في **المحاكاة**.
9. **مراجعة الإعدادات**: الترقيم والاستقبال ووقت الانتظار والأمان والخصوصية والإشعارات.
10. **الشاشات والصوت وأجهزة التسجيل الذاتي**: اتبع دليل الشاشات.

وتكرر **قائمة التحقق قبل التشغيل** في آخر هذا الدليل الأساسيات.

### 4.2 إضافة مدينة (المسؤول العام)

1. افتح **المدن** واضغط **إضافة مدينة**.
2. أدخل الاسم بالعربية والإنجليزية و**الرمز** (أحرف A-Z وأرقام وشرطة وشرطة سفلية، مثل `DAM`).
3. احفظ. تظهر المدينة كبطاقة تعرض عدد فروعها.

في كل بطاقة مدينة منطقة **الإعدادات**. تعرض عدد الإعدادات التي تخصصها المدينة، وعدد تخصيصات الفروع، وعدد أسباب الزيارة المخفية. استخدم **فتح إعدادات المدينة** لتعديلها. واستخدم **نسخ من مدينة أخرى** ثم **نسخ الإعدادات** لبدء مدينة جديدة من مدينة قائمة. يستبدل هذا إعدادات المدينة الجديدة المخصصة وأسباب الزيارة المخفية فيها؛ ولا تُنسخ تخصيصات الفروع ولا الورديات ولا قوالب الرسائل.

لا يمكن أرشفة المدينة إلا إذا لم يكن فيها فروع نشطة.

### 4.3 إضافة فرع وطوابق ومكاتب

1. افتح **الفروع والمكاتب** واضغط **إضافة فرع**.
2. اختر **المدينة**، وأدخل **رمز الفرع** و**العنوان** و**المنطقة الزمنية**. المنطقة الزمنية مهمة: فإعادة ترقيم التذاكر والتقارير تتبعان توقيت الفرع نفسه.
3. حدد **الفرع الافتراضي** إن كان كذلك. احفظ.
4. في بطاقة الفرع اضغط **إضافة طابق** إذا كان المبنى من عدة طوابق.
5. اضغط **إضافة مكتب**. أدخل **الرقم** (يظهر على الشاشات ويُنطق، مثل «المكتب 3»)، واختر **الطابق**، وإن كنت تستخدم شاشات متعددة المناطق فاختر **المنطقة**.

استخدم مرشح المدينة في الأعلى لتضييق القائمة. وإذا كنت تستخدم القاعات (غرف يستقبل فيها مضيف واحد عدة زوار معاً) فأضفها من خانة **القاعات** في الفرع بالزر **إضافة قاعة**: **رقم القاعة** و**السعة** (اثنان على الأقل) و**الخدمات المقبولة**. لا تعمل القاعات إلا بعد تفعيلها من **الإعدادات ← القاعات**.

![الفروع والمكاتب](shot:admin-branches)

### 4.4 إنشاء أسباب الزيارة وحقول البيانات

سبب الزيارة هو خدمة، مثل «تجديد عقد». كل تذكرة تتبع سبباً واحداً.

1. افتح **أسباب الزيارة** واضغط **إضافة سبب**.
2. في **المعلومات الأساسية** أدخل الأسماء، و**الرمز** (حروف إنجليزية صغيرة، يُستخدم في التقارير)، و**بادئة التذكرة** (من حرف إلى 3 أحرف عربية أو لاتينية، مثل `A`). واختر **الأولوية الافتراضية**.
3. في **أهداف الخدمة** حدد **مدة الخدمة المتوقعة (دقيقة)** و**مدة الانتظار المستهدفة (دقيقة)**. يستخدم الهدفَ التقارير وترتيب الانتظار، وتستخدم المدةَ المتوقعة تقديراتُ وقت الانتظار.
4. حدد **يظهر أولاً في الاستقبال** ليصبح زراً كبيراً لإصدار التذكرة بلمستين.
5. في **بيانات الزائر المطلوبة** حدد فقط الحقول التي تحتاجها فعلاً (اسم الزائر، رقم الجوال، الشركة، آخر 4 أرقام من الهوية، البريد، ملاحظات). واضغط **إضافة حقل مخصص** لغيرها. الحقول غير المحددة لا تظهر.
6. في **مكان تقديم الخدمة** اختر **مكتب** (زائر واحد في كل مرة) أو **قاعة** (عدة زوار معاً).
7. في **المواعيد** حدد **السماح بالمواعيد** عند الحاجة. وفي **جهاز التسجيل الذاتي** اختر هل يكتب الزائر هذه الخدمة بنفسه أم أنها **تحتاج موظفاً**.
8. في **من يخدم هذا السبب** اضغط **إضافة موظف** أو **إضافة مجموعة**. لكل منهم حدد **الكفاءة** (من 1 إلى 5) واجعله **أساسي** أو **احتياطي**. يستقبل الاحتياطيون التذاكر عند انشغال الأساسيين.
9. احفظ.

> **تنبيه:** السبب الذي لم يُسند إليه أحد يظهر باللون الأحمر بعبارة **لا أحد مُسند**: لا يمكن خدمة تذاكره حتى تُسند إليه أحداً.

يمكنك أرشفة سبب لم تعد تستخدمه. يختفي من الاستقبال ويبقى في السجل والتقارير.

![أسباب الزيارة](shot:admin-reasons)

### 4.5 إنشاء المستخدمين والموظفين

1. افتح **المستخدمون** واضغط **إضافة مستخدم**.
2. أدخل **البريد الإلكتروني** و**الاسم الكامل** و**الجوال** و**اللغة المفضلة**.
3. تحت **الأدوار** اضغط **إضافة دور**. لكل صف اختر **الدور** و**النطاق**: **المؤسسة بالكامل** أو مدينة (كل فروعها) أو فرع واحد. لا يستطيع مسؤول المدينة اختيار المؤسسة بالكامل.
4. لمن يخدمون الزوار فعّل **يخدم الزوار** وحدد **يعمل في فرع** و**المكتب الافتراضي** (أو **القاعة الافتراضية** للمضيف) و**أقصى عدد تذاكر في وقت واحد** و**وزن التوزيع** و**المجموعات** و**الوردية**.
5. **كلمة مرور أولية**: اكتب واحدة أو اتركها فارغة. إذا تركتها فارغة ينشئ دور رابطاً لتعيين كلمة المرور صالحاً 72 ساعة ويرسله إلى المستخدم بالبريد كرسالة تفعيل (إذا كان البريد مهيأً). ويظهر الرابط على الشاشة أيضاً لتنسخه إن لم يكن البريد مهيأً.
6. احفظ.

> **ملاحظة:** رسائل التفعيل والدعوة والموافقة جاهزة بصياغة عربية وإنجليزية مدمجة في النظام، ولا تحتاج إلى كتابتها.

افتح أي مستخدم من القائمة لتعديله. وفي النافذة أيضاً هذه الإجراءات:

| الإجراء                        | الأثر                                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **إعادة تعيين كلمة المرور**    | يُسجَّل خروج المستخدم من كل الأجهزة ويُنشأ رابط جديد لمرة واحدة صالح 24 ساعة. خيار **إرساله بالبريد الإلكتروني أيضاً** يرسله بالبريد. |
| **إلغاء التحقق بخطوتين**       | يوقف التحقق بخطوتين، مثلاً عند فقدان الهاتف.                                                                                          |
| **تسجيل الخروج من كل الأجهزة** | ينهي كل جلسات المستخدم.                                                                                                               |
| **تعطيل** / **تفعيل**          | يمنع الدخول أو يعيده. يبقى السجل محفوظاً. لا يمكنك تعطيل نفسك أو آخر مسؤول.                                                           |
| **إخفاء الهوية**               | يحذف الاسم والبريد والهاتف والصورة نهائياً. يبقى الحساب في السجل كمستخدم محذوف. لا يمكن التراجع.                                      |

يعني القفل بجانب المستخدم أن حسابه مقفل بعد محاولات دخول فاشلة كثيرة؛ والضغط على **تفعيل** يزيل القفل أيضاً.

### 4.6 دعوة الأشخاص

الدعوة تتيح للشخص أن يختار كلمة مروره بنفسه.

1. في **المستخدمون** اضغط **دعوة**.
2. أدخل بيانات **المدعو** (**البريد الإلكتروني** و/أو **الجوال**) والاسم.
3. اختر **الدور** والفرع و**لغة الدعوة**.
4. تحت **الإرسال عبر** حدد **البريد الإلكتروني** أو **واتساب** أو **رسالة نصية**، أو اختر **نسخ الرابط فقط**. ثم اضغط **إنشاء الدعوة**.
5. يعرض دور الرابط. وإذا كانت القناة غير مهيأة تظهر عبارة «غير مهيأ. انسخ الرابط وأرسله بنفسك.»

افتح تبويب **الدعوات** لمتابعة كل دعوة: **بانتظار القبول** أو **مقبولة** أو **منتهية** أو **ملغاة**. **إعادة الإرسال** تنشئ رابطاً جديداً ويتوقف القديم. و**إلغاء** يلغي دعوة قيد الانتظار. تبقى الدعوة صالحة للمدة المحددة في **الإعدادات ← الأمان ← صلاحية الدعوة (ساعة)**.

### 4.7 الموافقة على طلبات التسجيل أو رفضها

إذا فعّلت **السماح بطلب حساب من صفحة التسجيل (يوافق المسؤول على كل طلب)** في **الإعدادات ← الأمان**، يظهر في صفحة الدخول رابط **اطلب حساباً**. يملأ الشخص اسمه وبريده وهاتفه ويختار كلمة مرور.

1. افتح **المستخدمون** ثم تبويب **الطلبات**. تدل شارة رقمية على عدد الطلبات المنتظرة.
   ![تبويب الطلبات وفيه طلبات الحسابات المنتظرة](shot:admin-requests)
2. اضغط **موافقة** على الطلب. اختر **الدور** والفرع ثم أكّد. يستطيع الشخص تسجيل الدخول فوراً بكلمة المرور التي اختارها، وتصله رسالة بريد.
3. أو اضغط **رفض**. يُبلَّغ الشخص بأن طلبه لم تتم الموافقة عليه، ويمكنه التقديم مجدداً.

لا يحصل أحد على صلاحية قبل موافقتك. أوقف الإعداد عندما لا تريد استقبال طلبات.

### 4.8 الأدوار والصلاحيات

افتح **الأدوار والصلاحيات**. هناك أربعة أدوار أساسية: **المسؤول العام** و**مسؤول المدينة** و**موظف استقبال** و**موظف خدمة**. تحمل علامة **أساسي** ولا يمكن تعديلها أو حذفها. وقد يكون في مؤسستك أدوار مخصصة تحمل علامة **مخصص**.

لإنشاء دور مخصص (للمسؤول العام فقط):

1. اضغط **نسخ** على دور أساسي، أو **دور جديد**.
2. أدخل الاسم وحدد **الصلاحيات** المطلوبة. وهي مجمّعة (الإدارة، المستخدمون والأدوار، المنشأة، الخدمات والتوزيع، التذاكر والمواعيد، الموظف، التقارير والمتابعة، حماية البيانات، التكاملات).
3. احفظ.

**قاعدة منع التصعيد:** لا يستطيع أحد أن يمنح دوراً، أو يضع في دور صلاحية، لا يملكها هو نفسه. لذلك لا يستطيع مسؤول المدينة منح دور فيه صلاحيات على مستوى المؤسسة مثل إدارة المدن أو الإعدادات أو الأدوار.

![الأدوار والصلاحيات](shot:admin-roles)

### 4.9 مجموعات الموظفين

المجموعة فريق، مثل «خدمة العملاء». أسند مجموعة إلى سبب زيارة بدل ذكر كل موظف.

1. افتح **مجموعات الموظفين** واضغط **إضافة مجموعة**.
2. أدخل الاسم، واختر **المشرف**، وأضف **الأعضاء**.
3. احفظ.

### 4.10 الورديات والاستراحات

- **الورديات**: من **الإعدادات ← الموظفون** اضغط **إضافة وردية**. أعطها **الرمز** ووقت بداية ونهاية. إذا كانت النهاية قبل البداية فالوردية تمتد إلى ما بعد منتصف الليل. للمدينة ورديات خاصة بها إضافة إلى ورديات المؤسسة. ثم أسند الورديات للموظفين من نافذة المستخدم.
- **كيف تُستخدم الورديات** فيها ثلاثة خيارات. **تُتجاهل**: الورديات مجرد تسمية. **استرشادي (موصى به)**: تُستخدم في التقارير، ولا يُسند إلى الموظف خارج ورديته تلقائياً لكن يمكن مناداته يدوياً. **صارم**: لا يستطيع الموظف أن يصبح متاحاً خارج ورديته ويُسجَّل خروجه بعد انتهائها (بعد مهلة بالدقائق).
- **أنواع الاستراحات**: من **الإعدادات ← أنواع الاستراحات** (المسؤول العام). أضف أنواعاً بـ **الحد الأقصى بالدقائق** وحدد هل **يُحتسب وقتاً منتجاً**.
- **حد الاستراحات**: من **الإعدادات ← حد الاستراحات** لتحديد عدد موظفي الفرع الذين يمكن أن يكونوا في استراحة معاً.

### 4.11 قواعد التوزيع

افتح **قواعد التوزيع**. استخدم **تنطبق على** في الأعلى لاختيار **جميع الفروع (افتراضي)** أو فرع واحد أو سبب زيارة في فرع. يمكن للنطاق الأضيق أن يتجاوز الافتراضي.

1. اختر **طريقة التوزيع**:
   - **السحب (نمط البنوك)**: تنتظر التذاكر في القائمة ويضغط الموظف **استدعاء التالي**.
   - **الإسناد التلقائي**: تُحجز كل تذكرة لموظف فوراً حسب خطوات الاستراتيجية التي تحددها. تُطبَّق الخطوات بالترتيب وكل خطوة تحسم التعادل المتبقي من السابقة: **الأقدم تكليفاً**، **الأقل تذاكر منتظرة**، **الأطول فراغاً**، **الأعلى كفاءة أولاً**، **موزون (حسب وزن الموظف)**، **عشوائي**، **تناوب صارم**.
   - **هجين**: إسناد تلقائي، وإن لم يستدعِ الموظف التذكرة خلال الدقائق المحددة تُتاح للجميع ويمكن تنبيه المشرف.
   - **يدوي**: يختار موظف الاستقبال أو المشرف الموظف.
   - **بالتناوب (دور بدور)**: ترتيب ثابت، ويُتخطّى الغائب أو المشغول.
2. اضبط **الترتيب داخل قائمة الانتظار** (أوزان مدة الانتظار والأولوية والاقتراب من هدف الخدمة، ودفعة المواعيد، ومسارات الأولوية، و**الحد الأقصى المضمون للانتظار**، و**زيادة الأولوية مع الوقت**).
3. حدد **سعة الموظف** و**الاستعانة بالموظفين الاحتياطيين** و**الزوار العائدون** (تفضيل الموظف الذي خدم الزائر آخر مرة) و**سياسة عدم الحضور** (إعادة نداء تلقائية ثم إغلاق التذكرة أو إرسالها إلى نهاية القائمة).
4. احفظ. تظهر عبارة **تم حفظ القواعد. تُطبَّق من التذكرة التالية.**

عندما يكون للفرع أو للسبب قواعد خاصة تقول الصفحة **هذا النطاق يتجاوز القواعد الموروثة.** استخدم **إزالة التخصيص** للعودة إلى الافتراضي.

![قواعد التوزيع](shot:admin-distribution)

### 4.12 تجربة القواعد بالمحاكاة

قبل تغيير القواعد الفعلية جرّبها على يوم افتراضي.

1. افتح **المحاكاة**.
2. اختر **الفرع**. وفي **الزوار** اختر **يوم مولَّد** (حدد **عدد الزوار** و**نسبة كبار الشخصيات** و**نسبة كبار السن**) أو **إعادة يوم فعلي** (اختر **اليوم المراد إعادته**).
3. اختر **الموظفين**. واستخدم **موظفون إضافيون افتراضيون (ماذا لو)** لترى أثر زيادة العدد.
4. تحت **القواعد المراد مقارنتها** أبقِ **القواعد الحالية** واضغط **إضافة بديل** لإضافة بدائل.
5. اضغط **تشغيل المحاكاة**. يقارن جدول **النتائج** متوسط الانتظار ووسيطه وانتظار 90% من الزوار وأطول انتظار و**ضمن الهدف (٪)** و**العدالة**، ويحدد **الأفضل**. وتعرض الرسوم عدد المنتظرين خلال اليوم وعدد الزوار لكل موظف.

تستخدم المحاكاة محرك النظام الفعلي نفسه لكنها لا تغيّر أي تذكرة حقيقية. ومن **قواعد التوزيع** يأخذك الزر **جرّب هذه القواعد في المحاكاة** إليها مباشرة.

### 4.13 الإعدادات

يحدد مبدّل **يسري على** المستوى الذي تعدّله. تُورَّث القيم من المؤسسة ثم المدينة ثم الفرع. في القسم الذي يسمح بذلك فعّل **تخصيص لهذه المدينة** (أو الفرع) لتكون لذلك المستوى قيمته الخاصة. و**إعادة إلى الافتراضي** يزيل التخصيص. يعرض كل قسم مصدر قيمته الحالية. وينبهك شريط **لديك تغييرات غير محفوظة** لتضغط **حفظ** أو **تراجع**.

### 4.14 الإشعارات وقوالب الرسائل

افتح **الإشعارات**. تُبلغ الزوار برقمهم ودورهم ونداء المكتب. فيها أربعة تبويبات:

- **القنوات**: تعرض **واتساب** و**رسائل نصية** و**البريد الإلكتروني** بحالة **مُعدّة** أو **غير مُعدّة** أو **وضع تجريبي (لا يُرسل شيء)**. تُضبط مفاتيح المزوّدين وكلمات مرورهم على الخادم بمعرفة من يثبّته (للبريد إعدادات SMTP، ولواتساب مفتاح WhatsApp Cloud API، وللرسائل النصية بوابة رسائل أو Twilio). ولا تظهر هنا أبداً. استخدم **إرسال رسالة تجريبية** لإرسال نموذج إلى هاتفك أو بريدك (للمسؤول العام).
- **الأحداث والحدود**: اختر الأحداث التي تُرسل (**إصدار الرقم** و**اقتراب الدور** و**النداء إلى المكتب** و**فوات النداء** و**الشكر بعد الزيارة**) وعلى أي قناة، و**ترتيب القنوات**. تحمي الحدود الزوار من كثرة الرسائل. أبقِ **تذييل إلغاء الاشتراك**. لا تُرسل الرسائل إلا إذا وافق الزائر عند الاستقبال وترك رقم هاتف أو بريداً. ويمكن للفرع أن يتبع الافتراضي أو يكون له اختياره.
- **نصوص الرسائل** (للمسؤول العام): عدّل الصياغة لكل حدث وقناة، مع قيم يمكنك إدراجها (رقم التذكرة والمكتب والانتظار وغيرها). و**استعادة الصياغة الافتراضية** تعيد النص الأصلي. ولواتساب يمكنك إدخال **اسم قالب واتساب المعتمد**.
- **سجل الإرسال**: كل رسالة مع حالتها (**في الانتظار** أو **قيد الإرسال** أو **أُرسلت** أو **فشلت** أو **لم تُرسل**) وسبب عدم الإرسال. استخدم **إعادة الإرسال** على الرسالة الفاشلة.

![الإشعارات](shot:admin-notifications)

### 4.15 إعدادات الأمان (المسؤول العام)

في **الإعدادات ← الأمان**:

- **سياسة كلمات المرور**: **الحد الأدنى للطول**، واشتراط حرف كبير أو صغير أو رقم أو رمز خاص.
- **القفل بعد محاولات دخول فاشلة** و**مدة القفل (دقيقة)**.
- **صلاحية الدعوة (ساعة)**.
- **السماح بطلب حساب من صفحة التسجيل...**: انظر 4.7.
- **أدوار يلزمها التحقق بخطوتين**: حدد الأدوار. يلزم أصحابها استخدام التحقق بخطوتين.

### 4.16 التقارير والتقارير المجدولة

افتح **التقارير** من الشريط العلوي (يلزمها صلاحيات التقارير، وكلا دورَي المسؤول يملكها). اختر فترة (**اليوم** أو **أمس** أو **آخر 7 أيام** أو **آخر 30 يومًا** أو **هذا الشهر** أو تواريخ مخصصة) ومرشحات (الفرع وسبب الزيارة والموظف والقاعة والساعات وأيام الأسبوع). تعرض الصفحة المؤشرات الرئيسية وساعات الذروة وطول الطابور والموظفين وأسباب الزيارة والتوقعات وتكرار الزيارات والورديات وطرق إصدار التذاكر والقاعات ورضا الزوار.

- **تنزيل** يصدّر بصيغة **إكسل (.xlsx)** أو **CSV** أو **PDF** مع الأقسام التي تختارها.
- افتح **التقارير المجدولة** في الأسفل واضغط **إضافة تقرير مجدول** لإرسال تقرير بالبريد تلقائياً. اختر **التكرار** (**كل يوم** يغطي اليوم السابق، و**كل أسبوع** يغطي الأيام السبعة المنتهية أمس) و**وقت الإرسال** و**صيغة الملف** و**لغة التقرير** والفرع و**المستلمون** (عنوان بريد في كل سطر) والأقسام. و**إرسال الآن** يجرّبه. إذا لم يكن البريد مهيأً فلن يُرسل شيء.

### 4.17 أدوات الخصوصية والاحتفاظ بالبيانات

تتولى **طلبات الخصوصية** طلب زائر يريد الاطلاع على بياناته.

1. افتح **طلبات الخصوصية**. اكتب رقم هاتف أو اسماً أو رقم تذكرة واضغط **بحث**.
2. اختر الزائر. ترى ما هو محفوظ عنه (التذاكر والمواعيد والتقييمات والإشعارات).
3. **تصدير JSON** أو **تصدير CSV** يمنح الشخص بياناته.
4. للحذف اضغط **حذف الآن**، واكتب **السبب** (بلا أسماء أو أرقام)، وحدد **أؤكد التحقق من هوية الشخص وأريد حذف بياناته.** ثم أكّد. يُحذف الاسم والهاتف والشركة وتُمسح الملاحظات والتعليقات. تبقى التذاكر والدرجات في التقارير. لا يمكن التراجع.

يُسجَّل كل طلب في **سجل الطلبات** دون بيانات الشخص. ولحذف البيانات الشخصية لموظف استخدم **إخفاء الهوية** في نافذة المستخدم.

**الاحتفاظ** (**الإعدادات ← الاحتفاظ بالبيانات**، للمسؤول العام): حدد عدد الأيام التي بعدها تُخفى هوية بيانات الزائر، وتُمسح ملاحظات التذاكر وإجابات الاستمارة، وتُمسح تعليقات التقييم، وتُمسح تفاصيل الإشعارات، وتُحذف سجلات التدقيق، وتُحذف سجلات الدخول المنتهية. القيمة **0** تُبقي تلك البيانات حتى تحذفها يدوياً. تعمل المهمة تلقائياً مرة كل يوم تقريباً. **معاينة** تعرض ما سيتغيّر دون تغيير شيء. و**تشغيل الآن** ينفذها نهائياً. وفي **الإعدادات ← حماية البيانات** **نص الموافقة في نموذج الاستقبال** و**اشتراط الموافقة قبل إصدار التذكرة**.

### 4.18 سجل التدقيق

افتح **سجل التدقيق**. يعرض كل صف **الوقت** و**المستخدم** و**الإجراء** و**العنصر** و**التفاصيل**، مع قيم **قبل** و**بعد** للتغييرات. رشّح حسب نوع العنصر من **كل العناصر**، واضغط **عرض المزيد** للسجلات الأقدم. استخدمه للإجابة عن سؤال «من غيّر هذا الإعداد؟».

![سجل التدقيق](shot:admin-audit)

### 4.19 النسخ الاحتياطي

تُؤخذ النسخ الاحتياطية بنصوص برمجية على الخادم وليس من هذا التطبيق. اطلب ممن يدير الخادم جدولتها، واقرأ الملف `docs/backup-restore.md`. وتعرض بطاقة **النسخ الاحتياطي لقاعدة البيانات** في نظرة عامة هل نجحت آخر نسخة.

## 5. ممارسات جيدة ونصائح

- امنح كل شخص أصغر دور يحتاجه. استخدم دوراً مخصصاً مثل المشرف (التقارير ولوحة المتابعة وإعادة إسناد التذاكر) بدل جعل شخص مسؤولاً.
- أبقِ مسؤولَين على الأقل حتى لا تفقد الوصول.
- اضبط المنطقة الزمنية لكل فرع قبل أول تذكرة.
- استخدم **المحاكاة** قبل تغيير قواعد التوزيع في فرع مزدحم.
- راجع **سجل الإرسال** بعد تهيئة أي قناة، وأرسل لنفسك رسالة تجريبية.
- راجع **سجل التدقيق** بانتظام، خاصة الأدوار والمستخدمين والإعدادات.
- اجمع من بيانات الزائر ما تحتاجه فقط وحدد مدد الاحتفاظ.
- تأكد أن لكل سبب زيارة موظفاً أساسياً واحداً على الأقل، وأن في كل فرع طريقة لإصدار التذاكر.

| صفحة في هذا الدليل غير موجودة في الشريط الجانبي | دورك لا يشملها. لا يملك مسؤول المدينة صفحة **المدن** ويرى أقساماً أقل في **الإعدادات**. اسأل مسؤولاً عاماً.                  |
| «غير مصرّح بالدخول»                             | دورك لا يملك الصلاحية. اطلب من مسؤول عام تغيير دورك.                                                                         |
| لا أستطيع منح دور لشخص                          | يمكنك منح الأدوار التي تملك صلاحياتها فقط، وضمن نطاقك فقط.                                                                   |
| تذاكر خدمة ما لا تُستدعى أبداً                  | افتح سبب الزيارة: ربما لم يُسند إليه أحد، أو الموظفون المسندون غير مسجلين دخولهم أو خارج ورديتهم (**الإعدادات ← الموظفون**). |
| فرع لا يستطيع إصدار التذاكر                     | تبيّن لك بطاقة التحذير في نظرة عامة السبب. أضف موظف استقبال، أو فعّل إصدار التذاكر من شاشة الموظف، أو اقرن جهاز تسجيل ذاتي.  |
| لم تصل رسالة بريد إلى مستخدم جديد               | قد لا يكون البريد مهيأً (**الإشعارات ← القنوات**). انسخ الرابط من النافذة وأرسله بنفسك.                                      |
| رابط الدعوة توقف عن العمل                       | انتهت صلاحيته أو استُبدل بـ **إعادة الإرسال**. أعد إرسال الدعوة.                                                             |
| مستخدم مقفل                                     | افتح المستخدم واضغط **تفعيل**، أو انتظر مدة القفل. واستخدم **إعادة تعيين كلمة المرور** عند الحاجة.                           |
| مستخدم فقد هاتفه                                | افتح المستخدم واضغط **إلغاء التحقق بخطوتين**.                                                                                |
| تغيير إعداد لا يظهر في فرع ما                   | قد يكون للفرع تخصيصه الخاص. استخدم مبدّل **يسري على** وراجع شارة المصدر.                                                     |
| لا تصل الرسائل إلى الزوار                       | تحقق من حالة القناة، ومن أن الحدث مفعّل، ومن موافقة الزائر عند الاستقبال، ومن سبب عدم الإرسال في **سجل الإرسال**.            |
| بدأ ترقيم التذاكر من جديد في وقت غريب           | راجع **وقت إعادة ترقيم التذاكر يومياً** والمنطقة الزمنية للفرع.                                                              |

## 7. مرجع سريع

| أريد أن...                              | اذهب إلى                                                               |
| --------------------------------------- | ---------------------------------------------------------------------- |
| إضافة مدينة                             | **المدن ← إضافة مدينة**                                                |
| إضافة فرع أو طابق أو مكتب               | **الفروع والمكاتب**                                                    |
| إضافة خدمة                              | **أسباب الزيارة ← إضافة سبب**                                          |
| إسناد موظفين إلى خدمة                   | سبب الزيارة ← **من يخدم هذا السبب**                                    |
| إنشاء مستخدم                            | **المستخدمون ← إضافة مستخدم**                                          |
| الدعوة بالبريد أو واتساب أو رسالة نصية  | **المستخدمون ← دعوة**                                                  |
| الموافقة على طلب حساب                   | **المستخدمون ← الطلبات ← موافقة**                                      |
| إعادة تعيين كلمة مرور أو التحقق بخطوتين | افتح المستخدم ← **إعادة تعيين كلمة المرور** / **إلغاء التحقق بخطوتين** |
| إنشاء دور مخصص                          | **الأدوار والصلاحيات ← نسخ** أو **دور جديد**                           |
| تغيير طريقة إسناد التذاكر               | **قواعد التوزيع**                                                      |
| تجربة القواعد بأمان                     | **المحاكاة ← تشغيل المحاكاة**                                          |
| تغيير الشعار والألوان والترقيم          | **الإعدادات**                                                          |
| ضبط قواعد كلمة المرور والتحقق بخطوتين   | **الإعدادات ← الأمان**                                                 |
| ربط البريد وواتساب والرسائل النصية      | **الإشعارات ← القنوات** (المفاتيح تُضبط على الخادم)                    |
| تعديل صياغة رسائل الزوار                | **الإشعارات ← نصوص الرسائل**                                           |
| جدولة تقرير بالبريد                     | **التقارير ← التقارير المجدولة**                                       |
| حذف بيانات زائر                         | **طلبات الخصوصية**                                                     |
| معرفة من غيّر شيئاً                     | **سجل التدقيق**                                                        |
| اقتران الشاشات والأجهزة وضبط الصوت      | **الشاشات** (راجع دليل الشاشات)                                        |

## 8. قائمة التحقق قبل التشغيل

قبل اليوم الأول تأكد من الآتي:

1. **اسم المنشأة** و**الشعار** مضبوطان، وتذكرة تجريبية تبدو سليمة.
2. لكل فرع **المنطقة الزمنية** الصحيحة ومكاتب بأرقامها وطريقة لإصدار التذاكر (موظف استقبال أو إصدار من شاشة الموظف أو جهاز تسجيل ذاتي).
3. لكل سبب زيارة **بادئة تذكرة** ومدة متوقعة وهدف انتظار وموظف أساسي واحد على الأقل.
4. كل الموظفين لديهم حسابات بالدور والنطاق الصحيحين، وللموظفين **مكتب افتراضي** و**وردية**.
5. **قواعد التوزيع** مضبوطة ومجرَّبة في **المحاكاة**.
6. **وقت إعادة ترقيم التذاكر يومياً** والأرقام ووقت الانتظار مضبوطة.
7. **الإعدادات ← الأمان**: سياسة كلمات المرور، والتحقق بخطوتين للمسؤولين، وصلاحية الدعوة، وقرار إعداد طلبات التسجيل.
8. البريد مهيأ؛ وواتساب والرسائل النصية إن كنت تستخدمهما. وصلت رسالة تجريبية. وصياغة رسائل الزوار مراجَعة.
9. نص الموافقة ومدد الاحتفاظ مضبوطة.
10. الشاشات والصوت وأجهزة التسجيل الذاتي مقترنة ومفحوصة (راجع دليل الشاشات).
11. النسخ الاحتياطية مجدولة وبطاقة **النسخ الاحتياطي لقاعدة البيانات** خضراء.
12. يوجد مسؤولان على الأقل، لكل منهما تحقق بخطوتين.
